ovadm installs and gets out of the way. From here on, Puppet looks after your servers like any other node.

**What you'll learn:**

* Giving each server a role in `manifests/site.pp`
* Managing the server with [openvox_server](https://forge.puppet.com/modules/miharp/openvox_server)
* Node data by certificate name, and switching the CA off on compilers
* Checking that the first Puppet run changes nothing ovadm set up

This page is an outline so far.
